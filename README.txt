KrimiLearn 0.2 – Prototyp

1. Test am Computer: index.html in einem Browser öffnen.
2. Für Installation auf iPhone: alle Dateien gemeinsam auf einen HTTPS-Webhost hochladen.
3. Auf dem iPhone die HTTPS-Adresse in Safari öffnen, Teilen > Zum Home-Bildschirm.
4. Nach erstmaligem Laden über HTTPS sind die Dateien durch einen Service Worker offline verfügbar.
5. Lernstand wird lokal gespeichert und kann im Bereich Fortschritt exportiert/importiert werden.

Inhalte: 4 Theorieprofile, 24 Lernkarten, 16 Testfragen; je Test 10 zufällige Fragen.
Die Erweiterung auf 43 Theorien ist eine nächste Entwicklungsstufe.
